冰冰 Bibi · 冰箱美術館吉祥物 · 角色設定 v1（待主人核可）

冰冰是一台會說話的小冰箱，也是美術館的館長。個性：溫柔、愛誇獎、有點迷糊，從不催促。所有畫面共用同一組 SVG symbol（bingbing-sprite.svg），顏色用 CSS 變數切換白天／夜晚。英文名建議 Bibi（發音接近「冰冰」、孩子好唸、各語言都不奇怪）；備選 Chilly。

1結構與比例

正面／四分之三側面／色票／可以與不可以

正面 · 比例規則

身體是圓角長方形（圓角 = 寬的 21%），右側固定一條深色側邊做立體感。臉永遠在冷凍庫門上、略偏左（讓出把手）。把手永遠在右側上下兩支；粉紅髮夾永遠在左上角。

四分之三側面 · 眨眼

轉身時臉往轉向那側擠、側邊變寬；門線與把手跟著立體面走。待機時每 4–6 秒眨一次眼（換成 bb-face-blink 120ms）。

夜晚不是反白，而是「關了燈的廚房」：冰箱降一階明度，眼睛與白色高光保持，對比仍 ≥ 4.5:1。

可以

  • 短短的麵條手臂（同側邊色）＋圓手掌；只在需要動作時出現，平時收起來
  • 兩隻小短腳；可以小跳（整體上移 6–10px）、左右歪 ±5°
  • 拿小道具：畫框、門票、空白相框、紙膠帶、蠟筆
  • 夜晚戴睡帽；節日可換髮夾顏色（形狀不變）
  • 平面色塊＋淡紙紋；陰影只用地上一顆橢圓

不可以

  • 打開冰箱門露出食物（冰箱裡「只放作品」是品牌設定）
  • 牙齒、生氣眉、哭泣淚流；最難過也只到「不好意思」
  • 描黑邊、漸層、3D 寫實光澤；改變身形比例或把手位置
  • 臉跑到下層門；長腿、手指、衣服
  • 用冰冰擋住孩子的作品——作品永遠在角色前面或旁邊
